# Library Ontology

An ontology for representing library and bibliographic information
using OWL and WebProtégé.

## Domain

Library and Bibliographic Information

## Classes

- Author
- Book
- BookCopy
- LoanMember
- Publisher
- Subject

## Object Properties

- hasAuthor
- hasCopy
- hasSubject
- publishedBy
- loanBook
- borrowedBy

## Data Properties

- title
- isbn
- shelfMark
- authorName
- publisherName
- publisherYear
- subjectName
- memberId
- memberName
- loanDate
- dueDate
- returnDate

## Example

The ontology includes an example book individual:

**Aadujeevitham**

It is connected to its author, publisher, subject,
and physical book copy through ontology properties.

## Tools

- WebProtégé
- Protégé Desktop
- OWL

## Purpose

The purpose of this project is to model library and
bibliographic information in a structured and machine-readable
ontology.
